# Changelog

All notable changes to this project are documented in this file.

## v1.1.0 - 2026-11-18

- Added administrator account provisioning with configurable roles and initial Credits.
- Added administrator password resets and member self-service password changes.
- Password changes revoke all existing web sessions and WorkBuddy API tokens.
- Added Docker image, Compose deployment template, persistent data Volume and container health check.
- Added production environment template, delivery checklist, iteration workflow and rollback guidance.
- Extended CI with a Docker image build.

## v1.0.0 - 2026-11-17

- Initial public release of the shared web and WorkBuddy image generation service.
